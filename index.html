How it works

What the system keeps

Check booking references, dates and currencies against their sources. Save each decision and its event together in Postgres. A worker reads this outbox after the commit and refreshes each team’s authorized views. It can safely handle a repeated update.

Supplier actions have a stable operation reference. Check price, expiry and approval each time. Verify the supplier’s reply before recording a completed action or releasing the original room.

Intent suggestions use a small local Naive Bayes classifier trained on fictional messages. People confirm the request before linking records. The deadline and room checks use rules, and all demos use sample data.

What a TBO pilot would measure

Replay the same cases with the same staffing and compare missed cutoffs, time to assign an owner, incorrect links and the lead time for catching a supplier problem.
